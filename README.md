# AI מקומי

Android 13+ offline local AI assistant.

- Generic GGUF selection with Android Storage Access Framework.
- llama.cpp based local inference.
- Offline Whisper.cpp speech-to-text dependency.
- Local conversations.
- Modular Android action manager.
- No INTERNET permission, analytics, ads or cloud AI.
- Material icons are supplied by the Android Material Icons library; no emoji are used.

The intended initial model is Qwen2.5-0.5B-Instruct in GGUF. The model is not included.

GitHub Actions builds the APK and publishes it as a GitHub Release.
