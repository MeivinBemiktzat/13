# עיצוב אלבומים — Album Designer

אפליקציית אנדרואיד **חינמית ואופליין לחלוטין** לעיצוב אלבומים דיגיטליים ופוטו-בוקים,
בהשראת אתרים כמו albume.co.il — אבל הכול רץ במכשיר, בלי אינטרנט ובלי עלות.

* **חבילה:** `com.mikdash.albumdesigner`
* **minSdk 24 (אנדרואיד 7.0)** · **targetSdk 33 (אנדרואיד 13)** — ממוטב לאנדרואיד 13, רץ מאנדרואיד 7 ומעלה
* נבנה ללא Gradle/Android Studio — ישירות מ‑`aapt2 + javac + d8 + apksig`
* ה‑APK המוכן: `build/AlbumDesigner.apk`

## יכולות

- **פורמטים מרובים** — ריבוע, 4:3, 3:4, אלבום כפול, A4, סטורי 9:16, פנורמה 16:9
- **22 תבניות עיצוב מוכנות** (רומנטי, חתונה, תינוק, יום הולדת, טיולים, וינטג', פסטל, שחור‑זהב, פרחוני, זר פרחים, באנר מסיבה, שמי כוכבים, בוהו, מלכותי, חורף ועוד)
- **14 פריסות תמונות** (רשתות 2×2/3×3, קולאז'ים, מגזין, פסיפס, פולארויד…)
- **50 איורים וקטוריים מצוירים** — פרחים, זרים, עלים, באנרים, סרטים, כתרים, מדליות,
  מצלמות, מטוסים, מצפן, פרפרים, יונים, פתיתי שלג, כוכבים, עוגות, בלונים ועוד —
  כולם עם 2 צבעים שניתן לשנות (לא אמוג'י — גרפיקה חדה בכל גודל)
- **12 מסגרות דקורטיביות לתמונות** — קו/כפול/מקווקו/פינות/פולארויד/סרט צילום/גלי/זהב מעוטר…
- **9 פילטרים לתמונות** — שחור‑לבן, ספיה, חמים, קריר, וינטג', דהוי…
- **תמונות** מהגלריה (SAF — ללא הרשאות מיוחדות), עם עיגול פינות, מסגרת, זום ומיקום
- **טקסט** עשיר — 6 גופנים, צבע, גודל, מודגש/נטוי/קו‑תחתון, יישור, צל
- **72 אמוג'י** · **צורות** — מלבן, עיגול, משולש, לב, כוכב, קו
- **רקעים** — צבעים, 16 גרדיאנטים, **רקע מעגלי (זוהר)**, **10 דפוסים** (נקודות, פסים,
  שברון, לבבות, כוכבים, גלים…), תמונה, ו**אפקטי תאורה** (וינייטה / זוהר עליון)
- **עריכה חופשית** — גרירה, שינוי גודל, סיבוב, מרכוז אופקי/אנכי, שכפול, שכבות, שקיפות
- **ריבוי עמודים** לכל אלבום, שמירה אוטומטית, **ביטול פעולה (Undo)**
- **ייצוא** — שמירת כל העמודים כתמונות JPEG לגלריה, ייצוא כ‑**PDF**, ושיתוף

הכול נשמר בזיכרון הפנימי של האפליקציה — שום דבר לא עוזב את המכשיר.

## התקנה

העבירו את `build/AlbumDesigner.apk` למכשיר ופתחו אותו. אם נדרש, אשרו
"התקנה ממקורות לא ידועים". החתימה היא APK Signature Scheme v2 ולכן ההתקנה
תקינה באנדרואיד 7 עד 13 ומעלה.

## בנייה מחדש

צריך JDK 17+ ואת קבצי הכלים של אנדרואיד בתיקייה `../.tools/`:
`aapt2`, `android.jar`, `r8lib.jar`, `apksig.jar`.

```bash
./build.sh          # → build/AlbumDesigner.apk
```

הסקריפט מקמפל משאבים (aapt2), קוד Java מול `android.jar`, ממיר ל‑dex (d8),
אורז וחותם (apksig v2). מפתח חתימה נוצר אוטומטית בהרצה הראשונה.
