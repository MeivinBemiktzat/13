# KosherConnect — דיבורית בלוטוס חכמה למחשב

תוכנת Windows בעברית מלאה (RTL) שהופכת את המחשב ל"דיבורית בלוטוס" חכמה,
ומתחברת לכל טלפון — כולל פלאפון כשר — כדי לנהל שיחות, תא קולי, הקלטות,
בייביסיטר ועוד, ממשק אחד יפהפה ומעוצב.

בנויה ב-**Electron** — טכנולוגיה שמאפשרת עיצוב ברמת אתר מודרני (HTML/CSS)
בתוך תוכנת מחשב אמיתית.

---

## 📥 התקנה (למשתמש הסופי)

הורידו את קובץ ההתקנה מתיקיית [`installer/`](installer/):

```
installer/KosherConnect-Setup-1.0.0.exe
```

הריצו אותו — ההתקנה רגילה לחלוטין:
- בחירת תיקיית התקנה
- קיצור דרך בשולחן העבודה
- קיצור דרך ב**תפריט התחל** של Windows

לאחר ההתקנה התוכנה נפתחת אוטומטית ומופיעה תחת השם **KosherConnect**.

> התוכנה נפתחת במצב **הדגמה** מלא (כל הממשק פעיל) גם ללא חומרת בלוטוס,
> כדי שתוכלו להתרשם מכל היכולות מיד.

## 🔧 בנייה מהמקור (למפתחים)

```bash
cd kosher-connect
npm install
npm start        # הרצה במצב פיתוח
npm run dist     # בניית קובץ ההתקנה ל-Windows (dist/*.exe)
```

בניית ה-EXE מ-Windows עובדת ישירות. בנייה מ-Linux/Mac דורשת `wine`
(electron-builder משתמש בו כדי להטמיע אייקון ולבנות את מתקין ה-NSIS).

## 📡 על חיבור הבלוטוס לפלאפון כשר

המחשב מתחזה ל**יחידת דיבורית** (HFP — Hands-Free Profile), והטלפון משמש
כ"שער שמע" (Audio Gateway). כך גם פלאפון כשר, שמתוכנן להתחבר לדיבורית רכב,
יזהה את המחשב כדיבורית ויתחבר אליו.

השירות `bluetooth-service.js` בנוי עם **נקודת חיבור אמיתית לחומרה**:
בעת עלייה הוא מנסה לטעון מחסנית בלוטוס נייטיב (למשל `node-bluetooth-serial-port`).
אם היא מותקנת ונתמכת — עוברים לחיבור חי; אחרת התוכנה פועלת במצב הדגמה מלא.

> **הערה טכנית חשובה:** חיבור HFP חי שבו ה-PC תופס את ערוץ השמע והשיחות של
> הטלפון דורש מחסנית בלוטוס נתמכת ב-Windows והתאמה מול החומרה. השכבה מוכנה
> לחיבור, אך הפעלה חיה מלאה מול פלאפון פיזי דורשת בדיקה על המחשב עצמו.
